# Global Coupling

## Purpose
Test whether global feedback dominates locality.

## Method
The simulator uses the global feedback term $\gamma G_t$ in the local update and the separate global accumulator from the production code.

## Evidence
The continuous-injection experiment produced a much larger average tension and energy than the single-impulse case, showing that global feedback amplifies sustained forcing. However, the presence of diffusion and local nonlinear terms still matters because the local state evolves even when the global term is small.

## Conclusions
Global coupling matters, but the verified laboratory results indicate that local terms still shape the field strongly.

## Limitations
The current lab run does not include a dedicated ablation case that disables global coupling, so this conclusion is qualitative rather than fully isolated.
