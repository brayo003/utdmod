KEY:
  R(m=0.1)  = Readiness at low memory (fresh sources)
  R(m=1.0)  = Readiness at medium memory (typical active region)
  R(m=5.0)  = Readiness at high memory (old dormant regions)
  ★         = Recommended configuration

INTERPRETATION:
  R > 0.8   → Transport flows strongly; minimal suppression
  R > 0.5   → Transport flows moderately; noticeable suppression
  R > 0.2   → Transport flows weakly; strong suppression
  R < 0.1   → Transport nearly blocked; severe suppression

SELECTION GUIDE:
────────────────

Want gradual "fatigue" mechanics?
  → Use Exponential (scale = 2.0 to 3.0)

Want smooth, permissive propagation?
  → Use Rational (scale = 3.0 to 5.0)

Want discrete threshold switching?
  → Use Logistic (scale = 1.5 to 2.0, width = 0.8 to 1.0)

Want structural constraints?
  → Use Field-Depth (scale = 2.0 to 5.0)
  → WARNING: Pure field-depth is restrictive; consider combining with memory

Want multi-factor gating?
  → Use Combined (m_scale ≈ f_scale = 1.5 to 2.0)
  → WARNING: Dual gating very suppressive; test carefully

PARAMETER TUNING:
─────────────────

If transport too weak:
  1. Increase scale parameter by ~25%
  2. Example: scale 2.0 → 2.5
  3. Result: R values increase at all memory levels

If transport too strong:
  1. Decrease scale parameter by ~25%
  2. Example: scale 2.0 → 1.5
  3. Result: R values decrease; higher suppression

If wrong type of behavior:
  1. Switch to different readiness variant
  2. Exponential → Rational: softer decay
  3. Exponential → Logistic: threshold behavior
  4. Exponential → Combined: add structural constraint

TESTING PROCEDURE:
──────────────────

1. Set readiness parameters in ParameterSet.java
   Example:
   ```java
   readinessMemoryScale = 2.0;
   transportBalanceMode = "exponential";
   ```

2. Run GameplayValidationExperiments
   ```bash
   ./gradlew -p simulation_lab test --tests 'GameplayValidationExperiments'
   ```

3. Check output in run/gameplay_validation/balance_summary.txt
   Look for:
   - Peak activation: 0.1 - 1.0 (reasonable range)
   - Hotspot lifetime: 50-500 ticks (meaningful duration)
   - Radius: 2.0 - 20.0 (spatial extent)
   - Transport values: > 0.01 (nonzero transport)

4. Adjust parameters if needed:
   - Too much suppression? Increase scale
   - Too little suppression? Decrease scale
   - Wrong dynamics shape? Switch variants

5. Repeat until satisfied with behavior

CONVERGENCE NOTES:

After testing, if you need to lock in a configuration:

Recommended final parameters:
  readinessMemoryScale = 2.0
  transportBalanceMode = "exponential"

These should provide balanced, believable spatial dynamics.
